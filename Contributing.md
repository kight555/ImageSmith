# Contributing

Thank you for your interest in contributing! Whether it's reporting a bug, suggesting an improvement, or submitting code changes, your help is appreciated.

## Reporting Bugs
If you find a bug or run into an issue, please open an issue on the GitHub repository. Be sure to include:
* A clear description of the problem.
* Steps to reproduce the issue.
* Your operating system or environment details.

## Suggesting Enhancements
If you have an idea for a new feature or improvement, feel free to open an issue to discuss it before jumping into code.
